# 葵のダメージボイス

ユーザー指定の `shozyo2-u.mp3` を `assets/audio/aoi-hurt.mp3` にそのままコピーし、葵の被弾時だけ再生する。敵の声は追加しない。以前の合成音声2種類は使用しない。

- 変換・切り取りをせず、指定ファイルと同一バイト列を保存。元ファイル名・SHA256を `assets/audio/selected-voice.json` に記録。
- ブラウザでデコードした長さは0.544秒、ステレオ。音量は従来と同じ0.65。
- 再生中と終了後80msは追加の声を抑制。Mによるミュート、ポーズ、ステージ切り替えで現在の声を止める。
- 取得・デコード失敗時は声だけ無音になり、ゲームと打撃音を継続する。
- 古い合成音声と生成処理は履歴用に保存してあるが、ゲームは読み込まない。

## 確認

Node.js 12件、Python 7件成功。指定音声1ファイルの読み込み、連続被弾の重なり防止、同じ素材の再利用、ミュート、失敗時の継続、保存したファイルのハッシュを確認。

実ブラウザでEnter入力からAudioContextがrunningとなり、指定MP3だけがデコードされて再生開始できることを確認。コンソールのエラー・警告なし。葵の被弾への接続と敵では鳴らないことは、音声差し替え前の実ダメージ判定でも確認済み。
