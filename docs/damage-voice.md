# 葵のダメージ仮ボイス

葵の被弾時だけ「うっ」「くっ」を交互に鳴らす。敵の声は追加しない。既存の打撃音は継続し、短い声を重ねる。

- Windowsの日本語女性音声 Microsoft Haruka Desktop を System.Speech で合成した仮素材。演技付きの収録音声ではない。
- 先頭と末尾の無音を除去し、音量を調整、両端に5msのフェードを付けた。各約0.14秒、22,050Hz・モノラル16bit PCM WAV。
- キー・タッチ・ゲームパッドから音声を起動した際に読み込み、ゲーム開始を音声の読み込み待ちにしない。
- 再生中と終了直後80msは追加の声を抑制。Mによるミュート、ポーズ、ステージ切り替えで現在の声を止める。
- ファイル欠落・取得失敗・デコード失敗時は声だけ無音になり、ゲームと従来の効果音を継続。
- 生成元WAVは `source_art/audio/`、実際に使うWAVと生成情報・ハッシュは `assets/audio/` に保存。

再生成(日本語音声が入ったWindows):

```powershell
powershell -NoProfile -File tools/generate_aoi_voice.ps1
python tools/prepare_aoi_voice.py
```

## 確認

- Node.js 12件成功。葵だけの再生、重なり防止、音声の交互再生、ミュート停止、音声未起動時、取得・デコード失敗、同時入力での多重読み込み防止を含む。
- Python 6件成功。音声2ファイルの形式、長さ、無音でないこと、波形の両端、ピーク上限、ハッシュの一致を含む。
- 実ブラウザでEnter入力からAudioContextがrunningとなり、2音声がデコードされたことを確認。
- 実際の敵の攻撃判定で、葵のHP100→94と同時に声の再生数0→1、再生ノードがactiveになることを確認。
- Mでミュートし、声の停止・新規再生の抑制を確認。解除後、敵のHP36→30の攻撃では声の再生数が1のままであることを確認。
- 確認タブのコンソールにエラー・警告なし。音質・演技としての採用判断と物理端末での聞こえ方は別途必要。
