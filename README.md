# ストリートエンジェル 葵

女子高生ファイター「葵」が、ギャング団「黒蛇会」と戦う、横スクロールのベルトアクションゲーム(ブラウザで動作)。全3ステージ。

公開版(Claude アーティファクト、作成者のみ閲覧可): https://claude.ai/artifact/PkZN4J6bDh7Pp3EHtQQXMT

## 遊び方(ローカルで動かす)
```bash
python -m http.server 8765
# ブラウザで http://localhost:8765/street-angel.html を開く
```
`.claude/launch.json` に、同じ設定があります。`file://` では、素材の読み込みに失敗するので、必ず HTTP で開いてください。

操作: 矢印/WASD=移動、Z/J=パンチ(3連)、X/K=キック、Space=ジャンプ(+Z/Xで飛び蹴り)、C/L=必殺(ゲージ50%)、P=ポーズ、M=音のON/OFF。ゲームパッド(X=パンチ、B=キック、A=ジャンプ、Y=必殺、Start=ポーズ)と、スマホ用の画面ボタンにも対応。

## フォルダ構成
| 場所 | 内容 |
|---|---|
| `street-angel.html` | ゲーム本体(ゲームロジック、描画、音楽、入力、すべて) |
| `r3d.js` / `vendor/` | 旧3D描画の保存用。現在のゲームでは読み込まない |
| `damage-voice.js` / `assets/audio/` | 葵だけの指定MP3による被弾ボイス、重なり防止・ミュート連動 |
| `character-motion.js` | 攻撃判定に合わせたポーズ選択・体格・呼吸の設定 |
| `character-lab.html` | 5人の体格・構え・動き・向きを切り替えて比較 |
| `visual-style.js` | 敵の赤・青緑の部分だけを色替えする処理。陰影・肌色・透明度を保ち、読み込み時にシートをキャッシュ |
| `assets/` | ゲームが読み込む絵。`*_walk/atk/hit/jump/cmb.png` がスプライトシート、同名の `.js` が、コマの位置・基準点のデータ |
| `assets/orig/` | 色補正をする前の、葵のシート(元に戻す用) |
| `assets/unused/` | 使わなくなった試作のシート |
| `assets/*.b64.txt` | 3Dモデルと動き(Quaternius、CC0)を、base64 にしたもの。`LICENSE-quaternius.txt` 参照 |
| `source_art/` | ChatGPT で作った、元のスプライトシートとコンセプトアート(番号は作成順。`unused` は不採用) |
| `tools/` | 新素材は `pack_character_sheet.py`、旧素材は `slice3.py` で切り出し |
| `assets/characters/` | 新しい葵・チンピラ・ヤンキー・剛田のシートと検証記録 |
| `source_art/character-v2/` | 生成元画像・プロンプト・参照・再生成レシピ |
| `_work/` | 確認用の画像(並べた画像、頭の大きさの比較など)。なくても動く |

## 絵(スプライト)の作り方
1. ChatGPT で、緑(#00FF00)の背景に、ポーズを格子状に並べたシートを作る。
2. `tools/slice3.py` で、背景を消して、1コマずつ切り出し、位置と大きさを揃えて、`assets/` に書き出す。
   ```bash
   python tools/slice3.py <元画像> <列数> <行数> <基準コマ番号> <基準の高さ> <出力.png> <出力.js> <変数名> <基準色: red|teal|navy|brown> strict
   ```
   基準色は、体の中心を見つけるための色(キャラの上着やズボンの色)。`strict` は、足元の薄い影を消す指定。
3. 足を地面に付けて、支えにする行(攻撃、キック)は、足の中心に、基準点を直す(`slice2.py` の方式)。
4. 動きを確認する。並べた画像で、ループのつなぎ目、足の位置、頭の大きさ、色を、前のシートと比べる。

### シートのコマの並び(戦闘シート4×4、敵)
1行目: 待機、待機、被弾、よろめき / 2行目: 攻撃の4コマ(予備動作、命中、そのまま、戻し) / 3行目: 吹っ飛び(空中2コマ、着地、寝た姿) / 4行目: 起き上がり(寝た姿、起き上がる途中、片膝、立ち)

## 絵のスケール
各キャラは、頭の大きさ(頭のてっぺんからあごまで)で揃える。シートごとに `scale` を決めてある(`street-angel.html` の `ESET`、`WALK_K`、`SHEET_K`、`JUMP_K`)。全身の高さで揃えると、構えの姿(低い姿勢)が大きく見えて、頭身がずれる。

## 既知の限界
- 歩行素材には左右の足の入れ替わりが弱いコマが残る。葵の4コマ歩行は不採用にし従来の8コマ構成へ戻したが、厳密な接地・左右交互の手描きアニメーションには達していない。
- ボス(番長・剛田)は2D化済み。長ラン・リーゼント・赤い帯、拳・突進・叩きつけを描き分ける。生成素材のためコマ間で輪郭や衣装の細部に揺れがある。
- 大男の旧戦闘素材には、倒れた姿のコピーが残る。葵の被弾・ジャンプと、一般敵の歩行・大男の素材は従来シートを継続使用。
- ステージの背景はコード描画。商店街・裏路地の店舗や路面、アジトのレンガ・木箱には陰影と細部を追加済み。
- 音楽と効果音は、コードで作った簡単なもの(WebAudio)。BGMは今は止めてある(`street-angel.html` の `MUSIC` を `true` にすると鳴る)。
- デカブツの歩行シート最終コマと戦闘シートの構えは、元の絵で左右反転して描かれていた。歩行は並び(`walkSeq`)から外し、構えは反転修正してある(`_work/br_cmb_before_fix.png` が修正前)。

## デバッグ
`street-angel.html?debug` で開いたときだけ、`window.__game` (状態のぞき・ステップ実行・音楽テスト)が有効になる。通常のプレイ時は無効。

### 見た目の確認

小画面では体力・残機・スコア・必殺ゲージをゲーム画面の外に表示。横向きのタッチ端末では、ゲーム画面と44px以上の操作ボタンを同じ画面内に配置する。

色変換・ポーズ選択のテスト: `node --test tests/*.test.cjs` (Node.js 18以上)。実画面の確認結果と比較画像は [docs/visual-review/README.md](docs/visual-review/README.md) を参照。

## キャラクターの比較と素材の再生成
ローカルサーバー上で `character-lab.html` を開く。ゲーム内と同じシート・体格設定・ポーズ選択を使い、共通の接地線で比較できる。攻撃の例は葵のキックと各敵の基本技。ボスの2種類の大技は専用項目で確認する。

新素材の生成元・プロンプト・参照は `source_art/character-v2/recipes.json` に保存。透明な生成元は透明度を保ち、緑背景の生成元だけ背景を抜く。シート内の全コマに1つの倍率を使い、しゃがみ姿を立ち姿と同じ高さに引き伸ばさない。

```bash
python -m pip install -r source_art/character-v2/requirements.txt
python tools/pack_character_sheet.py
python -m unittest discover -s tests -p "test_*.py"
```

[キャラクターの変更・画像・確認結果](docs/character-review/README.md)を参照。保存してある旧3D素材は現在のゲームでは不要。配布するときはHTMLと読み込まれるスクリプト・画像を同じフォルダ構成で配信する。

## ダメージボイス
葵の被弾時だけ、指定された `shozyo2-u.mp3` を再生。敵の声はなし。Mで音声もミュートできる。[素材・再生成・確認結果](docs/damage-voice.md)を参照。
